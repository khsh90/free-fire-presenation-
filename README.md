# Khaled Kutiba Khashashneh Project 🔥

مشروع تفاعلي باللغة العربية عن لعبة **Free Fire**: القصة، مراحل الجولة، الأحداث داخل اللعبة، الشخصيات وقدراتها، الأوضاع، الخرائط، الأسلحة، وآخر تحديث (OB55).

**إعداد الطالب:** خالد قتيبة أحمد خشاشنة — الصف العاشر (ب)

## التنقل
- الأسهم ← → أو زر «التالي / السابق»
- السحب بالإصبع على الهاتف
- `M` لقائمة الأقسام، `F` لملء الشاشة

المصادر: الموقع الرسمي [ff.garena.com](https://ff.garena.com/en) وملاحظات تحديث OB55.
الصور والشعارات ملك لشركة Garena، واستُخدمت لغرض تعليمي فقط.
